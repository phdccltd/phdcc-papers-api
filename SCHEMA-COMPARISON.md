## Migration Required

### Single Migration Needed

**File**: `migrations/001-add-submits-composite-index.sql`

**What it does**:
```sql
CREATE INDEX user_flow_idx ON submits (userId, flowId);
```

**Why needed**:
- Optimizes the batch query in `getPubUsers` (routes/users.js:238)
- Query pattern: `WHERE userId IN (...) AND flowId IN (...)`
- Without composite index: uses only userId index, filters flowId in memory
- With composite index: optimal index scan for both columns

**Safety**:
- ✅ Idempotent (checks if index exists before creating)
- ✅ Non-destructive (only adds, doesn't modify data)
- ✅ No downtime (can be added while database is online)

**Impact**:
- Improves query performance on large submission datasets
- Part of 71% performance optimization for admin-users page
